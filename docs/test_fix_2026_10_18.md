- Counts from repeated/focused runs overlap and must not be added into a unique-test total. Synthetic inference and images test contracts/failure handling, not real-world model accuracy.

That run is retained as evidence and is superseded only by a complete sequential run. Browser commands must not share Flutter build output concurrently with VM tests.

The detected NVIDIA GPU does not certify the selected CPU-only runtime as CUDA-capable. No GPU throughput/concurrency or physical camera accuracy acceptance is claimed.
4. Local development settings still produce six deployment security warnings: DEBUG, development secret, HTTPS redirect, HSTS and secure session/CSRF cookies. Use and verify the opt-in production settings behind the intended TLS proxy; do not enable HSTS blindly against local HTTP.
5. Live Clerk revocation/renewal, real Retell lifecycle, physical media and target-browser/proxy acceptance require authorized external dependencies. Fixture success is not provider verification.
6. The installed Flutter Chrome unit-test backend is deprecated and needed the local Windows CanvasKit workaround to execute. All 14 targeted browser test bodies now pass; supported production app/plugin initialization, other browser engines and physical passkey devices still require separate acceptance.
7. The installed SimpleJWT/PyJWT metadata conflict is intentionally untouched. It is excluded from this repair, and SimpleJWT is not added to application authentication.
